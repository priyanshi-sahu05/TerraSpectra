# Mock Data

This directory contains controlled mock data used for developing
and testing the Member 3 Vision Transformer and FastAPI pipeline.

The mock data is temporary.

It will later be replaced or connected to the real hyperspectral
data and Member 2's 3D-CNN output.

## Purpose

Mock data allows Member 3 development to continue while the
Member 2 3D-CNN implementation is pending.

## Important

Mock tensor dimensions are development assumptions only.

They must not be treated as the final CNN interface.
